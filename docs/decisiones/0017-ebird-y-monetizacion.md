# 0017 — Se usa la API de eBird; monetización aparcada
Fecha: 2026-11-13 · Estado: vigente
Contexto: los datos de la API de eBird son de uso no comercial, y la visión pedía dejar la puerta abierta.
Decisión: de momento no se piensa en monetizar. Recientes y rarezas salen de la API de eBird.
Consecuencias: si algún día se monetiza, ese bloque hay que sustituirlo o quitarlo. Se sigue anotando la
licencia de cada fuente (spec 002), sin que condicione qué se usa.
