# 0015 — Una web, dos catálogos que no se fusionan
Fecha: 2026-11-13 · Estado: vigente
Contexto: "punto único" significa una sola web con recomendaciones de luz (paisaje, nocturna) y de fauna en
España, no una entidad "lugar" que mezcle las dos cosas.
Decisión: spots de luz y lugares de fauna son catálogos distintos, con ficha propia cada uno. Comparten un
núcleo de campos (spec 003) y se enlazan por cercanía ("fauna cerca", "luz cerca"), nada más.
Consecuencias: no hay ficha única ni reglas de fusión por distancia y nombre.
