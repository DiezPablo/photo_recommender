# 0008 — Orientación = horizonte real del terreno
Fecha: 2026-10-23 · Estado: vigente
Contexto: la orientación de un spot no viene en ninguna fuente.
Decisión: perfil del horizonte cada 2° hasta 60 km con teselas Terrarium (AWS, gratis), curvatura y
refracción. Se usa para la hora real de sol/luna sobre el relieve, la Vía Láctea sobre crestas y el panorama.
Consecuencias: base de la idoneidad del lugar; reutilizable para lugares de fauna si hiciera falta.
