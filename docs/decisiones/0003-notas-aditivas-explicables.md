# 0003 — Notas aditivas con desglose
Fecha: 2026-10-19 · Estado: vigente
Contexto: la nota tiene que poder explicarse ("qué suma y qué resta").
Decisión: cada nota = base + factores con nombre y puntos, recortada a 0-10; el desglose de la web es
exactamente esa suma. Sin modelos opacos ni IA.
Consecuencias: cualquier factor nuevo debe tener nombre y puntos visibles; nada de cajas negras.
